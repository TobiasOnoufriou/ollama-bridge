Settings

Local model answers in this chat (Local, and Smart when it stays local)

The bridge finds relevant code on this PC (outline, the model's picks, search by meaning) and attaches it, so plans use real names. No Claude tokens.
Step by step asks the model one small question at a time (which files, what changes in each, what else uses it), then checks the plan. Usually 15–60 s.

Claude Code the Claude button, and Claude / Smart in this chat

Higher effort thinks longer: better on hard tasks, slower and uses more.
From this chat nobody can approve edits, so Normal and Plan mode run as Auto-accept edits; the Plan box under the message decides when the chat plans.
The local model checks each plan step against what actually changed, plus syntax and unused new functions. Free; a fix round costs one short Claude turn.

Claude Code on a local model the Claude (local) button

Only models that make real tool calls can run Claude Code; others are greyed out.
